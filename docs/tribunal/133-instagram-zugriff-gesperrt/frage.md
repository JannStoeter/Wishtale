Wortlaut von Jann im Projekt-Chat (26.11.2026): „Instagram api Access Blocked“

Befund: Am 6.11. wurden drei Beiträge mit denselben Schlüsseln echt veröffentlicht. Am 26.11. um 05:42 Uhr scheitert der nächste Beitrag schon beim ersten Aufruf mit `API access blocked.` (Meta, OAuthException Code 200). Ein abgelaufener Schlüssel meldet sich anders (Code 190), darum liegt die Sperre bei Meta: Die Meta-App ist eingeschränkt oder im Entwicklungsmodus ohne passende Rolle, oder das Instagram-Konto muss eine Sicherheitsprüfung bestätigen. Das lässt sich nur in Meta lösen.
