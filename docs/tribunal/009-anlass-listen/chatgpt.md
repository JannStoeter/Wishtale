## Begründung

**Belegt:** Die allgemeine Anlass-Auswahl wurde aus dem Produkt entfernt. Eine Hochzeitsliste oder ähnliche Anlassliste hat andere Anforderungen als eine normale Wunschliste, etwa mehrere Schenkende, Beiträge zu Gemeinschaftsgeschenken und einen festen Termin.

Ich empfehle **eine spätere eigenständige Funktion**, nicht eine einfache Zweitliste im aktuellen Kern. Sie sollte erst umgesetzt werden, wenn Nutzerbedarf erkennbar ist und die Kernanwendung stabil funktioniert.

**Vermutung:** Eine echte Anlassliste könnte eine neue Zielgruppe erschließen, sollte aber nicht als bloßer Filter der bestehenden Wunschliste umgesetzt werden.

**Nicht geprüft:** Nachfrage, Zahlungsbereitschaft und konkrete Anforderungen für Hochzeit, Geburt, Taufe oder andere Anlässe.

## Risiken

- Eine neue Funktion kann Produkt und Navigation unnötig verkomplizieren.
- Gemeinschaftsgeschenke und Beiträge benötigen zusätzliche Regeln.
- Ohne Nachfrage droht Entwicklungsaufwand ohne Nutzung.

## Gegenargument

Eine einfache Zweitliste wäre ein günstiger Nachfrage-Test. Wenn Nutzer heute bereits mehrere Listen wünschen, könnte ein kleiner Prototyp schneller Erkenntnisse liefern als das Warten auf eine vollständige Anlassfunktion.
