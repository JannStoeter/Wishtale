`index.html`: Der Knopf „Zu meinem Wishtale“ in der Kopfzeile der Landingpage (sichtbar mit Sitzung) führt auf `app/#wuensche` statt auf `app/#profil`. Die Gastansicht hat seit 075 stattdessen den Avatar mit dem Menü. Das Anmelden und Bestätigungslinks landen in der App bereits auf `#wuensche`. Weitere Verweise auf `#profil` (zum Beispiel „Profil ergänzen“) bleiben, weil sie gezielt das Profil meinen.
